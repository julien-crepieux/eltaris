# eltaris.fr

Site vitrine de la holding Eltaris : page blanche avec le logo centré.

## Mise en ligne sur Hostinger

1. hPanel → **Sites web** → eltaris.fr → **Gestionnaire de fichiers**.
2. Ouvrir `public_html/`, supprimer la page par défaut (`default.php` / `index.php`).
3. Téléverser `index.html`, `logo.png` et `favicon.png`.

Alternative : hPanel → **Avancé → Git**, dépôt `https://github.com/julien-crepieux/eltaris.git`,
branche `main`, répertoire vide (= `public_html`), puis activer le déploiement automatique.
